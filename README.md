# Road of Borrowed Names — voices

The recorded voices for *Road of Borrowed Names* (https://a-birdi.github.io/Road-of-Borrowed-Names/). The game fetches
these files from `ja-JP/` when a line is about to be spoken; nothing here is meant to be browsed.

All voices were synthesized locally on the developer's PC with free tools. No voice in this folder is a recording of a
real person speaking these lines.

## Engines and voices

- **AivisSpeech 1.2.0** (https://aivis-project.com/), under each model's AivisHub licence (ACML 1.0):
  - The narrator: **ほのか** (~現実20代女子AIボイチェン~リアボVC公式モデル). 声は(x.com/dopoiro)のAI
  - Other speakers: **まお**, **コハク**, **凛音エル**, **るな** (AivisHub).
- **VOICEVOX Nemo 0.24.0** (https://voicevox.hiroshiba.jp/nemo/): VOICEVOX Nemo (男声1, 男声2, 男声3), under the VOICEVOX
  Nemo terms (https://voicevox.hiroshiba.jp/nemo/term/).
- **Qwen3-TTS** (Qwen3-TTS-12Hz-1.7B-Base and -VoiceDesign, Apache-2.0): the companions, the player's voices and most
  other speakers, each from one designed reference voice. A few of the narrator's word readings are made with Qwen3-TTS
  cloned from the narrator's own readings, where the narrator's model could not say the word.
- **Mochi's meow**: "Meow of a pleading cat" by Heismark, Wikimedia Commons, public domain.

## Use

These files are part of the game. The terms of the voices above apply to any other use; in particular, VOICEVOX Nemo's
terms do not allow the voices to be used for machine learning.
